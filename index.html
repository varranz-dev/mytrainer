      Sincronización con Google Drive

      Elige (o crea) mytrain_state.json dentro de tu carpeta sincronizada de Google Drive. Requiere Chrome/Edge de escritorio. Funciona abriendo el HTML directamente (file://).

      Necesitas un OAuth Client ID (tipo "Aplicación web") de Google Cloud Console con la Drive API habilitada y tu origen autorizado (ej. http://localhost:8080 o tu GitHub Pages). No funciona desde file:// — sirve el HTML con python -m http.server 8080.

      Scope usado: drive.file (solo ve los archivos que crea esta app).
